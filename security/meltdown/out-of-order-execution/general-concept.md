Out-of-Order (OoO) execution is a microarchitectural optimization design that allows a processor to execute instructions as soon as their required operands and execution units become available, rather than waiting for prior instructions in strict code order. In traditional in-order execution pipelines, if an instruction encounters a latency delay—such as a cache miss or a long floating-point operation—the entire pipeline stalls, preventing subsequent independent instructions from executing. OoO execution overcomes this bottleneck by dynamically reordering the execution stream, keeping CPU execution units fully utilized while guaranteeing that the program's observable results match in-order execution semantics.

To achieve this, modern processors make a strict distinction between microarchitectural state and architectural state. Instructions are fetched, decoded, and dispatched in program order. Once dispatched, instructions sit in reservation stations or schedulers until their dependencies resolve. They execute out of order in parallel execution units as soon as data ready signals fire. However, the results are held in transient internal buffers and are committed to the architectural register file and memory in strict program order. This commit phase is known as instruction retirement. If an instruction triggers a fault, exception, or branch misprediction prior to retirement, the processor discards all uncommitted transient results, rolling back the microarchitectural state to the last valid architectural state.

In the context of hardware security and Meltdown, OoO execution creates a critical window of vulnerability known as transient execution. During this window, instructions that sit downstream of an invalid access or permission boundary (such as reading kernel memory from user space) can execute speculatively on transient data. Even though the reorder buffer will eventually drop these instructions when retiring the privilege fault, their execution mutates microarchitectural components like caches, leaving measurable side-channel traces behind.
